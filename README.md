# v1-adaptation-analysis
Statistical analysis of mouse V1 adaptation on Allen Brain Observatory ecephys recordings. Drifting-gratings only; spike counts vs repeat number; Wilcoxon, quartile splits, and Kruskal–Wallis by stimulus parameters, with reproducible notebooks and figures.

This repository analyzes adaptation in mouse primary visual cortex using recordings from the Allen Brain Observatory ecephys project. We restrict attention to drifting gratings so that each presentation is defined by orientation, temporal frequency, and spatial frequency, which allows a clean construction of a repeat counter for identical gratings within a session. Spike counts are computed for V1 units and paired with each presentation’s repeat number to study how responses evolve under repetition.

The main analysis fits a line to spike count versus repeat number for every neuron–condition pair and then aggregates slopes across pairs. The slope distribution centers slightly below zero, and a Wilcoxon signed-rank test confirms a small but significant negative trend, indicating that responses diminish with repetition. We further examine transient responses, quartile splits by firing rate, and stimulus-parameter effects. High-firing units show a steeper negative trend, and a Kruskal–Wallis test indicates adaptation depends on orientation but not on temporal frequency in the session analyzed, with insufficient variety to test spatial frequency robustly.

The notebooks are organized for reproducibility. Data selection builds the drifting-gratings subset and assigns repeat counts, the main analysis notebook runs the regressions and non-parametric tests, and the visualization notebook exports figures and summary tables. Figures and CSVs are written to versioned folders so results are easy to audit and extend. The code is concise and intended as a practical starting point for adding more sessions, expanding to additional stimulus types, or testing cross-session effects within a specimen.
